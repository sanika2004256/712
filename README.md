# 🌸 अस्तित्व (Astitva) सॅनिटरी पॅड फ्रँचायझी नोंदणी पोर्टल

महिला सक्षमीकरण आणि मासिक पाळी स्वच्छता जनजागृतीसाठी गावोगावी सॅनिटरी पॅडचे वितरण व विक्री केंद्र सुरू करण्यासाठी तयार केलेले परिपूर्ण व आधुनिक वेब ॲप्लिकेशन.

---

## 🌟 प्रमुख वैशिष्ट्ये (Key Features)

### १. अर्जदाराचा सुलभ नोंदणी प्रवाह (Step-by-Step Franchise Application):
1. **स्थान निवड (Cascading Dropdowns):**
   - **राज्य (State):** महाराष्ट्र (Maharashtra)
   - **जिल्हा (District):** महाराष्ट्रातील सर्व ३६ जिल्हे
   - **तालुका (Taluka):** निवडलेल्या जिल्ह्यातील सर्व अधिकृत तालुके
   - **गाव (Village):** तालुक्यातील सर्व खरी गावे (सर्च फिल्टरसह)
2. **अर्जदाराची वैयक्तिक माहिती:**
   - अर्जदाराचे पूर्ण नाव
   - संपर्क क्रमांक (मोबाईल व व्हॉट्सॲप)
   - ईमेल आयडी (पर्यायी)
   - सविस्तर पत्ता व पिनकोड
3. **फ्रँचायझी मॉडेल व व्यवसाय तपशील:**
   - 🌸 **ग्रामपंचायत / गाव पातळी केंद्र:** (गुंतवणूक: ₹१०,००० - ₹२५,०००)
   - 🏢 **तालुका वितरक फ्रँचायझी:** (गुंतवणूक: ₹५०,००० - ₹१,००,०००)
   - 🤝 **महिला बचत गट मॉडेल:** (गुंतवणूक: ₹१५,०००)
   - 🏪 **दुकान / रिटेल फ्रँचायझी:** (गुंतवणूक: ₹३०,०००)
   - दुकान / जागेची सद्यस्थिती (स्वतःची, भाड्याने, घरातून किंवा लवकरच घेणार)
4. **पावती व पुष्टीकरण:**
   - अर्ज सादर होताच तात्काळ अधिकृत अर्ज क्रमांक (`AST-FR-XXXX`) जनरेट होतो.
   - पावती प्रिंट किंवा PDF स्वरूपात जतन करता येते.
   - व्हॉट्सॲपवर थेट पावती शेअर करता येते.

---

### २. ॲडमिन पॅनेल व व्यवस्थापन (Admin Dashboard & PDF Export):
1. **रिअल-टाइम डेटा (Real-time Firestore Sync):**
   - सर्व अर्ज थेट **Google Firebase Firestore** डेटाबेसमध्ये संग्रहित होतात.
2. **KPI स्टॅट्स कार्ड्स:**
   - एकूण अर्ज, कव्हर झालेले जिल्हे, तालुके, प्रलंबित (Pending), संपर्क झालेले (Contacted) व मंजूर (Approved) अर्ज.
3. **फिल्टर व शोध:**
   - नाव, मोबाईल नंबर, गाव, तालुका किंवा अर्ज क्रमांकाने शोध.
   - जिल्हा व स्थितीनुसार फिल्टर.
4. **PDF मध्ये एक्सपोर्ट (Export to PDF):**
   - "PDF मध्ये एक्सपोर्ट करा" बटणावर क्लिक करताच सर्व अर्जदारांची सुबक व अधिकृत A4 प्रिंट-रेडी PDF टेबल जनरेट होते.
5. **Excel / CSV एक्सपोर्ट:**
   - १-क्लिकवर सर्व अर्जांचा डेटा `.csv` फाईलमध्ये डाउनलोड होतो.
6. **थेट व्हॉट्सॲप व कॉलिंग:**
   - अर्जदाराला ॲडमिन पॅनेलमधून १-क्लिकवर थेट कॉल किंवा व्हॉट्सॲप मेसेज पाठवता येतो.
